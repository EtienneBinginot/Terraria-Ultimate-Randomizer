# Ultimate Randomizer

A complete, configurable randomizer mod for Terraria (tModLoader 1.4.4), tied to each world.

## Features
- Random enemy and boss drops, random treasure bags, fishing crates and other bags
- **Coherent** mode: items keep their category and tier and unlock as bosses are defeated
- **Guaranteed shuffle** mode: every item is swapped with another of the same category and tier
- **Chaos** mode: anything from anywhere
- One seed per world, saved with the world and synced in multiplayer
- Coherent stack sizes, protected progression items, everything configurable

## Commands
- `/rseed` shows the world seed; `/rseed set <n>` and `/rseed random` change it (host only)
- `/rdebug item <name>`, `/rdebug npc <name>`, `/rdebug tier`, `/rdebug pool`
