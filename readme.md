# Ultimate Randomizer

A complete, configurable randomizer mod for Terraria (tModLoader 1.4.4), tied to each world.

## Features
- Random enemy and boss drops with vanilla-like drop tables, treasure bags, crates and other bags
- Random shops (value-based prices), recipes (same category and tier, value guard), shimmer transmutations
- Random chests, fishing, mined ores and pot loot
- Random enemy spawns (same tier, same movement) and random arrival order of town NPCs
- Boss and enemy stat multipliers, random starting kit
- **Coherent** mode: items keep their category and tier and unlock as bosses are defeated
- **Guaranteed shuffle** mode: every item is swapped with another of the same category and tier
- **Chaos** mode: anything from anywhere
- One seed per world, saved with the world and synced in multiplayer
- Coherent stack sizes, protected progression items, everything configurable (English and French)
- Discovery journal (J key)

## Commands
- `/rseed` shows the world seed; `/rseed set <n>` and `/rseed random` change it (host only)
- `/rjournal` opens the discovery journal
- `/rchests confirm` randomizes the chests of a world created before the mod (host only, once)
- `/rdebug item <name>`, `/rdebug npc <name>`, `/rdebug tier`, `/rdebug pool`
